问题

你大概已经填过几十遍了

  1. 同一个手机号，第 40 次复制粘贴。
  2. 表单嵌在 iframe 里，填完发现提交按钮在另一个框里。
  3. 手快把「毕业时间」填进了「离职时间」，提交前才发现。

这些活儿不该由人来做。

机制

四个真正干活的部件

它认得出来哪个框该填什么

按可信度加权打分：浏览器标准的 autocomplete 属性 6 分、关联 <label> 5 分、placeholder 3.5 分、name 3.2 分、 邻近文本 2.5 分……再叠三层消歧：

  • 负向词一票否决：「昵称」永远不会被当成「姓名」
  • 区块语义纠偏：「毕业时间」归教育经历，「离职时间」归工作经历
  • 枚举值佐证：选项里同时有「男」「女」，基本就锁定是性别

低于 3 分的候选一律不填——宁可不填，也不填错。

它填的是真值，不是假象

直接改 element.value 只会改 DOM，React / Vue 的内部状态不会跟着变， 用户提交时那一格仍然是空的——这是同类工具最常见的翻车点。 这个扩展走原型上的原生 setter，再依次派发 input / change / blur，让页面的校验与状态同步逻辑完整跑一遍。

嵌在 iframe 里也照样填

招聘表单常被嵌在 iframe 中。扩展向页面内所有框架广播，各框架填自己那一份， 后台按「报到了几个框架」等齐再汇总——不会因为某个框架慢就漏报结果， 也不会在顶层还没填完时提前收尾。

每填一个都要回头核对

每个字段填完立刻回读一遍，值不一致就标记为失败并说明原因。 结果面板列出成功 / 跳过 / 失败三栏，跳过和失败都带理由； 填错了点一下「撤销本次填充」就能把页面还原。

安装

四步装上，刷新页面就能用

下载扩展包 zip · 47 KB

解压后得到 resume-autofill-extension 文件夹，里面有 manifest.json。 加载时选这个文件夹。

  1. 打开扩展管理页 Edge 访问 edge://extensions/，Chrome 访问 chrome://extensions/。 两个浏览器的步骤完全一样。
  2. 开启「开发人员模式」 在页面左下角（Chrome 在右上角）把开关打开。
  3. 点「加载解压缩的扩展」 选中刚才解压出来的 resume-autofill-extension 文件夹。
  4. 刷新已经打开的标签页 内容脚本只在页面加载时注入，安装前就开着的页面需要刷新一次才会出现悬浮按钮。

装好后打开任意含表单的页面，右下角会出现「一键填写简历」按钮； 也可以点扩展图标，在弹窗里触发。首次使用记得先去简历管理页把示例内容改成你自己的。

边界

它现在还做不到什么

写清楚这些比堆优点有用——你大概不希望装完才发现某个招聘网站填不动。

  • 还没在真实招聘网站上验证过。 目前只在本地模拟表单和真实浏览器行为上跑过测试。真实站点的自定义组件实现各异，命中率需要你实际用过才知道。
  • 纯面板选择的日期控件填不了。 必须点日历翻页才能选日期的组件不会自动点选，会在结果面板里标成失败。 能手动输入的日期框没问题。
  • 省市区三级联动不支持。 需要逐级选择的下拉组件填不进去，会跳过。
  • 富文本编辑器只做简单写入。 复杂编辑器（比如带工具栏的自定义富文本）可能不生效。
  • 只填看得见的字段。 折叠起来或还没展开的表单，需要先展开再点填充。
  • 需要「读取所有网站」的权限。 这是「在任意网站都能用」的代价。如果只打算在个别网站用，可以自己改清单文件收窄权限。
